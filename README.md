# privacy-policies

Políticas de privacidad públicas (GitHub Pages) para aplicaciones de LexAuditTech / Jhostter.

## Aplicaciones publicadas

- **MiFinanzas** (`com.lextaudittech.mifinanzas`)
  - Archivo: [`mifinanzas.html`](./mifinanzas.html)
  - URL pública (GitHub Pages): `https://jhostter.github.io/privacy-policies/mifinanzas.html`

## Cómo agregar otro proyecto

1. Sube un archivo HTML nuevo en la raíz del repositorio (por ejemplo, `otra-app.html`).
2. Agrega su enlace dentro de [`index.html`](./index.html).
3. Con GitHub Pages activo (`Settings → Pages → Deploy from a branch → main / (root)`), quedará disponible automáticamente en:
   `https://jhostter.github.io/privacy-policies/otra-app.html`
